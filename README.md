# NTNH-328 (Nuclear Tech: New Horizons-328)
This is a fork of NTNH from which certain mods have been removed. The 328 mode in the HBM mod has been enabled. HBM’s crafting recipes have been completely overhauled, and the progression system has been altered; not only have costs increased, but advancing through space is now a mandatory requirement for development, with technological progression running parallel to space exploration. The quest system has also been entirely reworked.
